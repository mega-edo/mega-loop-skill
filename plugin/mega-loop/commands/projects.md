description: List your mega-loop projects (read-only; use /mega-loop:connect to pick one)
---
Call the mega-loop `list_projects` verb and show the user's projects **by name** (id in
parentheses). Read-only — to select the active project for this session, use `/mega-loop:connect`.
On `unauthorized`, run `/mega-loop:status` first — it checks setup and how to set the PAT.
